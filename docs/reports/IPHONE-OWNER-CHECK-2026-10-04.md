# iPhone owner check (OWNER DEVICE QA REQUIRED)

Use a real iPhone in Safari, after the SVG/PDF fix is live. Sign in to your own account.
**Use a label you have already downloaded within the last 7 days**: re-downloading the same label
in the Builder is free. Step 6 uses **one** credit (Composer sheets are always charged). Note your
credit balance before you start.

1. **Menu:** open clpeasy.com, tap ☰, then tap **Sign in**. The sign-in page opens in the same
   tab.
2. **Builder:** open that label from My Labels. Tap **View label**; the label preview appears. Tap
   **Hide label**.
3. **PNG:** tap **PNG**. In the Downloads list (the ↓ arrow in the address bar), the file opens as a
   clean label image.
4. **SVG:** tap **SVG**. The file saves or opens and shows the label. If it opens in a tab instead
   of saving, write that down.
5. **PDF:** tap **PDF**. A print view opens showing the label (not a blank page). If Safari says
   "Pop-up blocked", write that down.
6. **Composer (optional, uses 1 credit):** open Print Sheet, add the same label, and tap **🖨 Print
   / Save as PDF**. Check that the A4 sheet appears.
7. **Credits:** the balance has dropped by 0, or by 1 if you did step 6. Nothing more.

Reply with **OK** or the step number and what you saw, with a screenshot if anything differs.
