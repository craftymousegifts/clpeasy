# D3a — P202 and P308+P313 recognition — 10 October 2026

Task · D3a, rebuilt on a fresh branch from main `64bd3ee` (the original local branch `local/d3a-p202-p308p313` was not reachable from this session). Tier · High (regulatory wording). Status · development only — not approved for customer-facing release.

## Change

Smart Paste already extracted P202 and P308+P313 (including the `P308 + P313` and `P308/313` forms), but neither code was in `P_LIB`. So any supplier SDS that carried either code was blocked at Step 3 and at download as "not recognised". D3a adds one entry for each code to both copies of the library, in `builder.html` and `label-render.js`. The two copies stay identical.

| Code | Provisional wording |
|---|---|
| P202 | Do not handle until all safety precautions have been read and understood |
| P308+P313 | IF exposed or concerned: Get medical advice/attention |

Nothing else changes: extraction, `_pExclude`, P280, unknown-code blocking, every existing `P_LIB` entry, the renderer's fit and size rules, auth, payments and stored data.

## Evidence

- The wording is the GB CLP Annex IV text identified earlier, entered from that earlier finding. It has **not** been re-checked against legislation.gov.uk in this session.
- `tests/d3a-p202-p308p313-recognition.js` checks:
  - library entries and that the two `P_LIB` copies are byte-identical;
  - the chip grid;
  - Smart Paste extraction in the plain, `+`, spaced and `/` forms, followed by the real Step 3 gate;
  - shared-renderer SVG wording, with no unrecognised codes and the label still fitting;
  - that adjacent `P308,P313` still combine into the joint statement;
  - that unknown codes (`P999`) and an orphan `P308` still block;
  - that `_pExclude` is unchanged.
- The test fails on main and passes with the change.

## Open — release blockers

1. Verify both wordings against the current GB CLP Annex IV, Table 6.2 (legislation.gov.uk). Also check any conditions of use that apply to P202 and P308+P313.
2. P308+P313 contains the "advice/attention" slash. It must follow the separate P313 / P332+P313 wording decision; the provisional preference is "medical advice". It is deliberately left aligned with the current P313 entry.
3. Founder approval and the High-tier release gate, run in the Test environment, before any merge or deploy.
