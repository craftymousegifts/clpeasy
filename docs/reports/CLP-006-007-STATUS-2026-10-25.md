## 4. CLP-007 — #233 / #266 reconciliation (no code merged)

- **#233 (Stage A)** conflicts with #270 in `builder.html`.
  - Its P241 equipment-words logic builds library wording from code-only P241 ("Use explosion-proof equipment."). With #270, Smart Paste always uses the supplier's own sentence; code-only or incomplete P241 is blocked. That matches the CLP-007 rule "do not invent equipment; block when necessary". #233's Smart Paste P241 logic is therefore superseded.
  - Its six library entries (P202, P240, P241 base, P242, P243, P403+P235) only affect manually entered or legacy labels, not Smart Paste.
- **#266 (P103 / P313 wording)** merges cleanly but changes library text, which alters reopened legacy and manual labels. It stays **HOLD** as recorded.
- **Regulatory REVIEW items stay unchanged**: P308+P313, P310, H316/H401 and P284 with code-only P241. Nothing was added automatically.

**D2 implementation (`sds-supplier-wording.js`).** Only whole sentences matching two narrow forms are left off the label:
- "This document / safety data sheet / SDS / information is given / provided / supplied / intended for information only."
- "It is the (final) (product) manufacturer's / user's / customer's / purchaser's responsibility to establish / determine / ensure / check the labelling of the product(s)…"

They stay in the saved source text (`sourceSection22`) and are listed in the parser's `administrative` output. Anything else prints for review, for example "For professional use only.". Across the 100 stored Nikura extracts and the 9 supplied documents, the only administrative notes found are these two Supplies for Candles sentences.

**D5 implementation (`builder.html`).**
- Removed: the `smart-paste-excluded-note` element, its update function and the exclusion bookkeeping.
- Unchanged: the teal and amber SDS suitability notices (match, unverified, mismatch, concentrated oil with bottles) and the Step 3 size note. Because there is no longer a second notice, the support link now always appears on the suitability notice.
- `smart-paste-guidance-release-c` is rewritten for supplier wording (14 checks pass).
- No help page referred to the removed notice.
