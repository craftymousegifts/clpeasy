## 4. CLP-007 — #233 / #266 reconciliation (no code merged)

- **#233 (Stage A)** conflicts with #270 in `builder.html`.
  - Its P241 equipment-words logic builds library wording from code-only P241 ("Use explosion-proof equipment."). With #270, Smart Paste always uses the supplier's own sentence; code-only or incomplete P241 is blocked. That matches the CLP-007 rule "do not invent equipment; block when necessary". #233's Smart Paste P241 logic is therefore superseded.
  - Its six library entries (P202, P240, P241 base, P242, P243, P403+P235) only affect manually entered or legacy labels, not Smart Paste.
- **#266 (P103 / P313 wording)** merges cleanly but changes library text, which alters reopened legacy and manual labels. It stays **HOLD** as recorded.
- **Regulatory REVIEW items stay unchanged**: P308+P313, P310, H316/H401 and P284 with code-only P241. Nothing was added automatically.
