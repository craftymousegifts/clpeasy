## Decision needed: #257 amber box on real Nikura documents

The amber "possible" note appears when the product name line contains
"fragrance oil" or "essential oil". On the 5 Nikura SDSs this depends on copy
order, not on whether the SDS is neat or 10% in wax:

- product name copied on the same line as "Product:" → amber for **all five**,
  including the correct 10%-in-candle-wax SDSs ("…Fragrance Oil (10% in Candle
  Wax)"), saying it "may not cover your finished scented candle";
- product name on a separate line → only the neutral note for all five,
  including the neat oils.

Guidance only (labels and gates are unaffected), but the amber message is
wrong for a correct 10% SDS. Options: (a) release as is; (b) small fix: treat
"(N% in candle wax / wax / …)" in the product name as finished-product
information, so it shows the neutral note.
