builder.html — 6 new features:

Label language — dropdown in Step 1. English, French, German or combinations. Signal word and "Contains:" translate automatically on the label
Fragrance load calculator — 🧮 Calculate button in Step 2. Enter wax + fragrance weights, get the % plus a warning if over 12%. One tap to apply to the label
Batch +1 — button next to the batch field in Step 4. Auto-increments LOT-001 → LOT-002 etc, remembers last used
UFI Generator — in Step 4. Generate ↻ button creates a unique formatted UFI code from a hash of your account + label data. Saves with the label and appears in the footer band
QR safety code toggle — in Step 1 appearance. Adds a small QR code to the label linking to clpeasy.com/safety/[uid]
Label version history — saved labels with multiple saves now show a 🕐 v2 button. Tap it to see versions and restore any previous version

safety.html — new page, upload to GitHub root:

Clean mobile-friendly safety data sheet. Loads from Supabase when QR is scanned. Shows signal word, GHS diamonds, H statements with full descriptions, sensitisers, responsible person details, UFI code, and a safety warning. Falls back to localStorage for testing
